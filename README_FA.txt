Amin Keyboard - نسخهٔ اولیهٔ اندروید

ویژگی‌های نسخهٔ ۱:
- کیبورد فارسی با دکمه‌های قابل لمس
- تغییر بین فارسی و انگلیسی
- افزودن خودکار ۴ کشیده در تمام اتصال‌های مجاز
- پاک کردن حرف به همراه کشیده‌های خودکارِ قبل از آن
- فاصله، ویرگول، علامت سؤال و رفتن به خط بعد

نصب از طریق Android Studio:
1. ZIP را Extract کن.
2. Android Studio را باز کن و Open را بزن.
3. پوشهٔ AminKeyboard_Android_Project را انتخاب کن.
4. اگر SDK Platform 35 نصب نیست، از SDK Manager نصبش کن.
5. صبر کن Gradle Sync تمام شود.
6. گوشی را با USB وصل کن و USB debugging را فعال کن.
7. Run را بزن تا برنامه روی گوشی نصب شود.
8. برنامه را باز کن؛ «فعال‌سازی کیبورد» را بزن.
9. سپس «انتخاب Amin Keyboard» را بزن و آن را انتخاب کن.

نکات مهم:
- این پروژه سورس اولیه است؛ APK از پیش ساخته‌شده نیست.
- برای اولین Gradle Sync به اینترنت و Android SDK نیاز است.
- الگوریتم اتصال در این نسخه بر اساس مجموعهٔ حروف فارسی/عربی نوشته شده و باید روی کلمات واقعی آزمایش شود.
- فعلاً امکاناتی مثل پیشنهاد کلمه، ایموجی، کلیپ‌بورد، تم، تنظیمات تعداد کشیده و نگه‌داشتن طولانی کلیدها وجود ندارد.
- اگر کادر ورود برنامه‌ای از نوع خاصی باشد، ممکن است رفتار Enter یا ویرایش متن با آن متفاوت باشد.
